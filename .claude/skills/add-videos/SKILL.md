# 영상 담기

사용자는 **링크만** 줘도 돼요. 도구가 링크마다 유튜브 제목을 불러와 그룹·날짜·행사·멤버·곡을 읽고, 날짜·행사별로 공연을 나눠 담아요. Claude는 사용자가 덧붙인 말(“단체”, “사녹”, “곡은 Static”)만 요청에 옮기면 돼요. `data/videos.json`은 직접 고치지 않아요.

## 1. 요청 만들기

가장 단순한 요청(링크만):

```json
{ "videos": ["https://youtu.be/AAAAAAAAAAA", "https://youtube.com/shorts/BBBBBBBBBBB"] }
```

사용자가 말로 준 정보는 넣어요. 요청 전체에 해당하면 맨 위에, 링크 하나에만 해당하면 그 영상에 넣어요.

```json
{
  "group": "르니에",
  "date": "2026-10-23", "show": "뮤직뱅크", "label": "",
  "note": "레드 투피스",
  "setlist": ["Paper Moon", "Static"],
  "videos": [
    { "url": "https://youtu.be/AAAAAAAAAAA" },
    { "url": "https://youtu.be/BBBBBBBBBBB?t=31", "members": ["유나"], "song": "Paper Moon" },
    { "url": "https://www.youtube.com/shorts/CCCCCCCCCCC", "members": ["단체"], "song": "Static", "tags": ["세로"] },
    { "url": "https://youtu.be/DDDDDDDDDDD", "type": "full", "songs": [{ "song": "Paper Moon", "t": 0 }, { "song": "Static", "t": "3:34" }] },
    { "url": "https://youtu.be/EEEEEEEEEEE", "date": "2026-10-18", "show": "인기가요", "label": "사전녹화" }
  ]
}
```

| 필드 | 언제 넣나 |
|---|---|
| `group` | 사용자가 그룹을 말했을 때. 없으면 제목의 그룹명·영문명으로 정해요 |
| `date` `show` `label` | 사용자가 말했을 때. 없으면 제목에서 6·8자리 날짜, 음악 방송 이름(뮤직뱅크·인기가요·쇼! 음악중심·엠카운트다운·더 쇼·쇼챔피언, 줄임말 뮤뱅·인가·음중·엠카·쇼챔 포함), `@행사명`, 사녹 → label `사전녹화`를 읽어요 |
| `members` | 사용자가 멤버를 말했거나 제목에 없을 때. 단체 직캠은 `["단체"]`, 유닛·페어는 `["도희","세린"]` |
| `song` / `songs` | 사용자가 말했거나 제목에 곡이 없을 때. 곡 구분 없는 축제·콘서트 전체 영상은 `"전체 공연"`. 두 곡이 든 영상은 `songs` |
| `type` | 제목에 직캠/풀캠 단서도 멤버도 없을 때 |
| `t` | 곡 시작 초. URL에 `t=`가 있으면 자동 |
| `source` `tags` | 사용자가 말했을 때만(제목·방송사 채널에서 자동) |
| `setlist` `note` | 사용자가 무대 순서·의상을 말했을 때(공연이 하나로 정해질 때만 적용) |
| `pin` `thumbPos` | “이걸 대표로”, “위쪽이 보이게” |

요청 파일은 저장소 밖(스크래치 폴더)에 두거나 `-`로 표준 입력에 넘겨요. 행사명 표기는 기존 공연과 맞춰요(`node scripts/archive.mjs events <그룹>`). 축제·콘서트는 행사 이름 그대로.

## 2. dry-run

```bash
node scripts/archive.mjs add /path/req.json --create-songs --dry-run
```

`--create-songs`는 기본으로 붙여요. 제목의 따옴표 안 곡명이나 사용자가 말한 곡이 아직 없으면 곡 목록에 추가하고, 보고에 적어요.

출력 읽는 법:
- **`공연:` 줄**: 새로 만드는 공연인지 기존 공연에 더하는지. 공연이 여럿으로 나뉘었으면 날짜·행사가 맞는지 봐요.
- **`+` 줄의 `자동:`**: 제목에서 읽은 값. 사용자 말과 어긋나면 요청에 값을 명시해요.
- **`!` 경고**:
  - 이미 담은 영상(건너뜀)
  - 같은 날 다른 공연이 있음 → 행사명·label이 맞는지 봐요
  - 제목 날짜가 요청 날짜와 다름 → 사용자에게 확인해요
  - setlist에 없는 곡
- **`✗ 정할 수 없는 영상`(종료 코드 2)**: 아무것도 쓰지 않았어요. 이유별로 처리해요.
  - **그룹을 정할 수 없어요 / 멤버를 정할 수 없어요(제목에 이름은 있는데 등록 안 됨)**: `register-group` 스킬로 그룹·멤버를 등록하거나 보강한 뒤 다시 dry-run.
  - **날짜·행사·멤버·곡을 정할 수 없어요(제목에도 없음)**: 사용자에게 그 링크만 물어요. 나머지를 먼저 담아 달라고 하면 `--skip-invalid`.
  - **제목을 불러오지 못했어요**: 네트워크 차단이에요. 허용할 도메인을 알리고(`CLAUDE.md` 네트워크), 사용자 말로 채우거나 물어요. 제목·채널을 지어내지 않아요.

## 3. 실행·검증·커밋

```bash
node scripts/archive.mjs add /path/req.json --create-songs
node scripts/archive.mjs validate
```

`CLAUDE.md`의 Git 흐름대로 해요. 커밋 메시지: `담기: <그룹> <날짜> <행사>[ <label>] 영상 N개`. 공연이 여럿이면 `담기: <그룹> 영상 N개 (공연 M개)`.

## 4. 사용자에게 보고

- 공연별로: 새 공연인지, 담은 영상 수, 멤버·곡, 볼 주소(도구 출력의 `보기:` 해시를 Pages 주소 뒤에 붙여서)
- 자동으로 정한 값 중 확인할 만한 것(새로 만든 곡, 사녹 label 등)과 건너뛴 링크와 그 이유
- 그룹·멤버를 새로 등록했다면 `register-group` 보고 항목

## 예

> 링크 5개만 붙여 넣음

→ `{ "videos": [링크 5개] }`. 제목으로 공연 3개로 나뉘면 그대로 담고, 공연별로 보고해요.

> “르니에 10월 30일 엠카 직캠들이야. 유나, 도희 거고 마지막은 단체” + 링크 3개

```json
{ "group": "르니에", "date": "2026-10-30", "show": "엠카운트다운",
  "videos": [ { "url": "<1>", "members": ["유나"] }, { "url": "<2>", "members": ["도희"] }, { "url": "<3>", "members": ["단체"] } ] }
```

> “하이디어 사녹이랑 본방 섞여 있어” + 링크들

→ 제목에 “사녹”이 있으면 자동으로 label `사전녹화` 공연으로 나뉘어요. 제목에 없는 링크만 사용자에게 물어 `"label": "사전녹화"`를 넣어요.
